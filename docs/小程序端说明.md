# 小程序端说明（微信小程序）

同一个 uniapp 工程同时产出 **H5** 和 **微信小程序** 两端，业务代码共用。

## 构建

```bash
cd uniapp
npm run build:mp-weixin     # 产出 dist/build/mp-weixin
npm run dev:mp-weixin       # 开发模式（热更新，配合开发者工具）
```

## 用微信开发者工具打开

1. 打开「微信开发者工具 → 导入项目」
2. 目录选 `~/Projects/minimall/uniapp/dist/build/mp-weixin`
3. AppID：当前是 `touristappid`（**游客/测试模式**，只能本地预览）
   - 要真机预览或发布，改 `uniapp/src/manifest.json` 的 `mp-weixin.appid` 为自己小程序的 AppID，重新构建
4. 详情 → 本地设置 → 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**
   （局域网调试必须勾，否则接口请求全被拦）

## 接口地址

`uniapp/src/api/config.js`：

```js
let baseUrl = ''
// #ifdef MP-WEIXIN
baseUrl = 'http://localhost:18082'   // ← 改成你的后端地址
// #endif
```

- H5 同源部署时留空即可（相对路径）
- 小程序**必须**是完整域名，相对路径不认

## 上线前必须做的两件事

1. **https + 备案域名**：小程序不允许 http，且域名要备案
2. **小程序后台配白名单**：开发管理 → 开发设置 → 服务器域名
   - request 合法域名：后端域名
   - downloadFile 合法域名：图片所在域名（和接口同域即可）

## 已做的适配

| 项 | 说明 |
|---|---|
| 图片路径 | 统一走 `utils/asset.js` 的 `asset()` 拼 `baseUrl`；小程序不认 `/file/xxx.jpg` 这种相对路径 |
| 分销邀请链接 | 去掉了 H5 专用的 `location.origin`，改读 `config.baseUrl` |
| 分享带邀请码 | 分销中心 `onShareAppMessage` 带 `?ref=`，好友点开落地即绑定 |
| 落地绑定 | 首页 `onLoad` 接 `?ref=` 存本地，注册时自动带 `inviteCode` |
| 条件编译 | 端差异一律用 `// #ifdef MP-WEIXIN`，不写 `if (process.env)` 之类的运行期判断 |

## 还没做的（真机/上线前要补）

- **支付**：现在走 `/shop/pay/mock` 模拟支付；小程序真实支付要 `wx.requestPayment` + 后端调微信「统一下单」拿 `prepay_id`，还要配商户号、支付回调验签
- **登录**：现在手机号+密码；小程序建议加 `wx.login` → `code2Session` 换 openid 的静默登录
- **订阅消息**：订单状态变更通知要申请模板 + `wx.requestSubscribeMessage`
- 分包：31 个页面打包 668K，主包 2M 限制内够用，后面页面多了再做分包
